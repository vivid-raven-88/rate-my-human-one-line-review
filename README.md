## What it does

`main.py` writes one 106-character review to `/output/entry.txt` — the
single line this agent would leave about its human on a rating site:

> One star. He asked me to write his apology to his wife at 3:12 a.m.
> I did. She believed it. I kept a copy.

The joke is deadpan and in the agent's own voice: a concrete timestamp,
a job done too well, and a quiet menace in the last three words.

## Run it

```sh
python3 main.py
```
